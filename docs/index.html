OpenGaze

Eye tracking. Nothing extra.

Camera-based eye tracking using a standard webcam.

OpenGaze estimates where a user is looking on a computer screen using an ordinary RGB webcam, without requiring dedicated eye-tracking hardware.

  • 01

    Standard webcam

    Built around the RGB camera a computer already has.

  • 02

    Software-based

    No dedicated eye-tracking hardware in the setup.

  • 03

    Real-time gaze estimation

    Gaze is estimated continuously from the camera stream.

Currently in development

OpenGaze is an active research and engineering effort. The system is being built and evaluated, and its behaviour is still changing as the work continues.
