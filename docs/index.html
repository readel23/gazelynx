GazeLynx

Eye tracking. Nothing extra.

Camera-based eye tracking using a standard webcam.

GazeLynx estimates where a user is looking on a computer screen using an ordinary RGB webcam, without requiring dedicated eye-tracking hardware.

Core idea

  • Standard webcam

    Built around the RGB camera a computer already has.

  • Software-based

    No dedicated eye-tracking hardware in the setup.

  • Real-time gaze estimation

    Gaze is estimated continuously from the camera stream.

How it works

  1. 01

    Set up

    GazeLynx works with the webcam already attached to the computer and the monitor that camera is pointed at.

  2. 02

    Calibrate

    A short guided calibration adapts the system to the person sitting in front of the screen and to their setup.

  3. 03

    Track

    The estimated gaze point then follows the screen continuously, with an optional marker drawn on top of the desktop.

  4. 04

    Review

    Gaze can also be recorded locally and looked at afterwards instead of being watched live.

Approach

Local by design

Everything runs on the computer in front of the user. The camera is opened only when tracking is explicitly started, and no video leaves the machine.

Measured, not claimed

Accuracy depends on the camera, the lighting, the display and the person. Instead of advertising one universal number, GazeLynx checks a calibration against targets it has not seen and reports what it measured there.

Deliberately narrow

One person, one monitor, one camera. The scope is kept small so that the core problem can be solved properly before anything is built on top of it.

Possible directions

  • Accessibility

    Interaction that does not depend on using a hand.

  • Human–computer interaction

    Interfaces that can take attention into account.

  • Research

    Gaze data in settings without dedicated equipment.

  • Interface analytics

    Understanding which parts of a screen are actually looked at.

Status

Currently in development

GazeLynx is an active research and engineering effort. The system is being built and evaluated, and its behaviour is still changing as the work continues. There is no public release yet.
